# 자기소개서

## 지원 동기

에어프레미아 정보보안팀이 전사 정보보안 정책, 서비스·오피스 아키텍처 보안, 취약점 개선, 정보보호 관리체계까지 함께 담당한다는 점에 끌렸습니다. 저는 금융권 매매체결시스템과 금융보안데이터센터 환경에서 보안 인프라를 구축·운영하며, 보안이 단순 통제가 아니라 서비스 신뢰를 유지하는 운영 체계라는 관점을 갖게 되었습니다.

에어프레미아는 항공 서비스 특성상 고객 접점, 오피스 업무 환경, 클라우드 기반 IT 서비스가 모두 안정적으로 보호되어야 합니다. 저는 보안 솔루션 운영, SIEM 탐지 룰 검토, 방화벽·NAC·DLP 정책 자동화, 감사 대응 문서화 경험을 바탕으로 에어프레미아의 안전하고 신뢰할 수 있는 보안 환경 구축에 기여하고 싶습니다.

## 직무 역량

**AWS 및 인프라 보안 운영**

금융보안데이터센터와 클라우드 운영 환경에서 서버, 네트워크, 접근제어, 보안 정책을 함께 다뤄왔습니다. Cloudflare Workers 기반 서비스 운영과 보안성 검토 경험을 바탕으로 네트워크 보안, 접근 권한, 로그 흐름을 운영 관점에서 점검할 수 있습니다. 또한 개인 인프라와 포트폴리오 운영에서 Terraform, Grafana, Loki를 활용하며 클라우드와 관측성 기반 운영 흐름을 계속 확장하고 있고, 이 경험을 AWS 환경의 보안 운영 기준에도 빠르게 적용하겠습니다.

**보안 솔루션 운영 및 정책 관리**

넥스트레이드 매매체결시스템 구축·운영 과정에서 FortiGate, IPS, WAF, NAC, DLP, Splunk SIEM 등 네트워크·엔드포인트·로그 분석 계층의 보안 솔루션을 운영했습니다. 보안 장비는 단순히 설치하는 것보다 권한, 정책, 예외, 변경 이력을 일관되게 관리하는 것이 중요하다고 생각합니다. 방화벽 정책 조회와 NAC·DLP 정책 작업을 스크립트와 Ansible 기반 절차로 정리하며 수동 운영 부담을 줄여왔습니다.

**SIEM 탐지 및 보안 이슈 대응**

Splunk ES 기반 보안 이벤트를 관제하고 탐지 룰 조건을 검토하며, 알림·분류·조치 흐름을 운영했습니다. 알림 워크플로과 Slack/SMS 알림을 연동해 보안 이벤트 인지 흐름을 표준화했고, FortiManager API를 활용한 정책 조회 자동화로 원인 파악 시간을 줄이는 방향으로 운영을 개선했습니다. 에어프레미아에서도 SIEM 탐지 정책 운영과 침해사고 대응 절차를 실무적으로 다듬는 데 기여할 수 있습니다.

**협업과 문서화**

보안팀은 유관 부서와의 협업이 중요합니다. 저는 개발팀, 인프라팀, 운영팀과 함께 금융위원회 본인가 심사와 금융감독원 감사 대응 자료를 준비하며, 보안 요구사항을 현실적인 운영 절차와 문서로 바꾸는 경험을 쌓았습니다. 단순히 “안 된다”가 아니라 “이 방식이면 보안 요구와 업무 효율을 함께 만족할 수 있다”는 대안을 제시하는 방식으로 협업하겠습니다.

## 성장 의지

에어프레미아 공고의 우대사항인 IaC 기반 보안 자동화, SIEM 탐지 정책, EKS·Kubernetes 보안 운영은 제가 계속 강화하고 있는 방향과 맞닿아 있습니다. 현재 Terraform, Ansible, Kubernetes 보안, 클라우드 보안 아키텍처를 개인 인프라와 학습 프로젝트에서 다루며 역량을 확장하고 있습니다.

에어프레미아 정보보안 기술 담당자로서 클라우드 보안 운영, 보안 솔루션 정책 관리, SIEM 기반 탐지·대응 체계를 안정적으로 운영하고, 반복되는 보안 운영 업무를 자동화와 문서화로 개선하겠습니다.
