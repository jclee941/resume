# Foreign Company Application Packet Convention

This directory contains hand-crafted English application packets for foreign
companies. These packets are intentionally independent from the master resume
SSoT and are not generated.

## Targeting

- Primary roles: Security Engineer, SRE, Platform Engineer, Cloud Security
  Engineer.
- Preferred locations: remote, Seoul, Incheon, Gyeonggi.
- Tone: factual, concise, and suitable for English-language recruiting systems.
- Claims: avoid concrete percentages, ratios, headcounts, capacity numbers, or
  other quantified performance metrics unless a future task explicitly verifies
  and permits them.

## Packet Shape

- Keep the JSON contract required by
  `tools/scripts/utils/validate-application-variants.js`.
- Use additional packet metadata for target roles, location preferences, and
  working preferences.
- Keep content hand-written for the intended foreign-company audience instead
  of copying master text mechanically.
