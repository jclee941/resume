# 현대캐피탈 Cloud DevSecOps Engineer 자기소개서

## 1. 지원 동기

DevOps의 속도와 Security의 안전성은 종종 충돌하지만, 자동화와 표준화로 둘을 함께 달성할 수 있다고 믿습니다. 저는 금융권 보안 인프라를 구축·운영하며 보안 정책을 IaC로 코드화하고 CI/CD에 보안을 녹여 왔습니다. 금융권 클라우드 보안 거버넌스를 체계화하는 현대캐피탈에서, DevSecOps 표준 체계를 함께 만들고자 지원합니다.

## 2. 직무 관련 핵심 경험

**금융권 Hybrid Cloud 보안 (콴텍투자일임)**
금융보안데이터센터 온프레미스와 AWS를 연동한 하이브리드 환경에서 VPC·IAM·Security Group 보안을 운영하고, CloudTrail·GuardDuty 로그를 통합 분석했습니다. 직무기술서 우대사항인 "금융권 Hybrid Cloud 인프라 구축 및 네트워크 연동"을 직접 수행한 경험입니다.

**IaC·Automation 표준화 (넥스트레이드)**
FortiManager API를 연동해 방화벽 정책 배포를 자동화하고, Ansible 플레이북으로 보안 장비 설정을 표준화했습니다. 운영 작업을 코드로 표준화하여 반복 작업과 휴먼 에러를 줄이는 것이 제 핵심 강점입니다.

**DevSecOps 파이프라인 (펀엔씨)**
GitLab CI/CD 파이프라인에 보안 검수(SAST/Dependency Scan)를 통합하고, Kubernetes RBAC·Pod Security를 설정했습니다. 빌드–배포 단계에서 보안 위험 요소를 사전에 차단하는 흐름을 구축했습니다.

**침해위협 모니터링·운영 자동화 (아이티센 CTS)**
Splunk SIEM과 n8n·Python을 결합해 보안 이벤트 인지–분류–알림 흐름을 표준화하고, 인시던트 대응 절차를 자동화했습니다. 운영 단계에서 금융감독원 정기 감사를 대응했습니다.

## 3. 부족한 부분과 보완 계획

AWS Control Tower / Landing Zone 구축은 직접 설계 경험보다 운영·연동 경험이 많습니다. 다만 거버넌스·계정 분리 원리를 이해하고 있어 빠르게 학습할 수 있으며, CKS 취득을 준비하며 클라우드 네이티브 보안을 강화하고 있습니다.

## 4. 입사 후 포부

DevSecOps 표준 체계를 "보안이 개발 속도를 늦추지 않는" 방향으로 설계하겠습니다. CI/CD 보안 게이트와 IaC 보안 정책을 자동화하고, GuardDuty·SIEM 기반 위협 모니터링을 운영 자동화와 연결해, 금융 규제를 충족하면서도 운영 효율이 높은 보안 거버넌스를 정착시키겠습니다.
