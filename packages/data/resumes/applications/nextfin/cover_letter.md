# 넥스트증권 Cloud Security Engineer 자기소개서

## 1. 지원 동기

증권 서비스는 고객의 자산과 직접 맞닿아 있어, 보안이 곧 신뢰입니다. 저는 국내 최초 대체거래소인 넥스트레이드의 보안 인프라를 구축부터 운영까지 담당하며, 금융 서비스가 출범 전 어떤 보안 기준을 통과해야 하는지를 현장에서 체득했습니다. 새롭게 증권 서비스를 쌓아 올리는 넥스트증권에서, 클라우드 위에 단단한 보안 기반을 함께 설계하고 싶어 지원합니다.

## 2. 직무 관련 핵심 경험

**금융 클라우드 하이브리드 보안 운영 (콴텍투자일임)**
AI 투자일임 서비스의 AWS 환경에서 VPC·IAM·Security Group을 운영하고, 금융보안데이터센터 온프레미스와 AWS를 잇는 하이브리드 보안을 관리했습니다. CloudTrail·GuardDuty 로그를 통합 분석해 비정상 행위를 탐지하고, CCE 취약점 점검을 정기적으로 수행했습니다. 직무기술서의 "CloudTrail·GuardDuty·SIEM 기반 위협 탐지"는 제가 매일 다뤄 온 업무입니다.

**전자금융감독규정·컴플라이언스 대응 (넥스트레이드)**
금융위원회 본인가 심사 대응을 위해 보안 아키텍처를 설계하고 기술 문서를 작성했으며, 망분리 체계와 방화벽 이중화를 구축했습니다. 운영 단계에서는 금융감독원 정기 감사를 대응했습니다. ISMS·전자금융감독규정 기반 점검을 실무로 수행할 수 있습니다.

**DevSecOps 자동화**
GitLab CI/CD 파이프라인에 보안 검수를 통합하고, Python·알림 워크플로로 보안 로그 분석·리포팅·알림을 자동화했습니다. 반복적인 점검과 대응을 코드로 표준화해 휴먼 에러를 줄이는 방식에 익숙합니다.

## 3. 부족한 부분과 보완 계획

AWS Control Tower 기반 멀티 계정 운영은 직접 설계 경험보다 단일·하이브리드 운영 경험이 많습니다. 다만 IAM·SCP 개념과 조직 단위 권한 설계 원리를 이해하고 있어 빠르게 적응할 수 있으며, 현재 CKS(Kubernetes 보안) 취득을 준비하며 클라우드 네이티브 보안 역량을 확장하고 있습니다.

## 4. 입사 후 포부

입사 초기에는 기존 AWS 보안 구성과 CI/CD 파이프라인을 빠르게 파악해 취약점·오구성을 식별하고, CloudTrail/GuardDuty/SIEM 연계 탐지 정책을 정비하겠습니다. 이후에는 보안 점검과 대응을 Python·IaC로 자동화하여, 서비스가 성장해도 보안 운영 부담이 선형적으로 늘지 않는 체계를 만들겠습니다.
