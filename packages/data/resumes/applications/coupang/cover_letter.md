# 쿠팡 Senior Security Engineer 자기소개서

---

## 1. 지원 동기

쿠팡의 Senior Security Engineer 포지션에 지원합니다. 8년간 금융, 공공, 제조, 교육 분야에서 보안 인프라를 설계하고 운영하며, 규제 환경 속에서 안전한 시스템을 구축하는 일에 집중했습니다.

쿠팡은 글로벌 이커머스와 물류 인프라를 동시에 운영하며 방대한 고객 데이터와 실시간 거래를 처리합니다. 이런 환경에서 보안은 단순한 규제 준수를 넘어, 비즈니스 신뢰를 지키는 핵심 자산이라고 생각합니다. 특히 AWS 퍼블릭 클라우드 기반 인프라와 Kubernetes 컨테이너 환경에서의 보안 설계, 접근제어 및 인증인가 체계 구축에 기여하고자 지원하게 되었습니다.

넥스트레이드 대체거래소 보안 인프라 구축 및 운영을 통해 금융권 보안 요구사항과 규제 대응 경험을 쌓았습니다. 쿠팡의 글로벌 규모 인프라 보안을 책임지는 팀에서, 클라우드 보안 아키텍처와 자동화 기반의 프로activce한 보안 체계를 함께 만들어가고 싶습니다.

---

## 2. 직무 관련 핵심 경험

**AWS 클라우드 보안 인프라 운영**

㈜콴텍투자일임에서 **AWS VPC**, **IAM**, **Security Group**, **CloudTrail**, **GuardDuty**를 중심으로 AI 주식투자 서비스의 퍼블릭 클라우드 보안 인프라를 운영했습니다. 금융보안데이터센터 온프레미스 환경과 **AWS 클라우드 하이브리드 보안**을 동시에 관리하며, 양측 환경의 접근제어와 로그 감시 체계를 통합했습니다. **CloudTrail**과 **GuardDuty** 로그를 통합 분석하여 이상 징후를 탐지하고, **CCE 취약점 점검**을 통해 설정 오류와 보안 구멍을 사전에 차단했습니다. 또한 **Prometheus**와 **Grafana** 기반 보안 메트릭 모니터링 대시보드를 구축하여, 보안 상태를 실시간으로 가시화했습니다.

**컨테이너 보안 및 CI/CD 보안**

㈜펀엔씨에서 **Kubernetes RBAC** 정책과 **Pod Security** 설정을 담당하여 컨테이너 환경의 접근제어와 워크로드 격리 체계를 구성했습니다. **Docker** 기반 컨테이너 환경에서 보안 기준을 수립하고, **GitLab CI/CD** 파이프라인에 보안 검수 단계를 자동화하여 배포 전 보안 정책 위반 여부를 사전에 차단했습니다. 이 경험은 쿠팡의 Kubernetes/EKS 기반 컨테이너 보안과 CI/CD 보안 강화에 직접 적용할 수 있습니다.

**IaC 기반 보안 자동화**

㈜콴텍투자일임에서 **Terraform** 기반 인프라 보안 정책을 코드로 관리했으며, ㈜가온누리정보시스템에서는 **Ansible** 플레이북과 **FortiManager API**를 연동하여 방화벽 정책 배포를 자동화했습니다. 수백 건의 방화벽 정책을 수동으로 배포하던 절차를 API 기반 자동화로 전환하여, 정책 일관성과 배포 신뢰성을 확보했습니다. 이런 IaC 및 API 기반 보안 자동화 경험은 Terraform Sentinel Policy 기반 정책 관리와 CSPM Misconfiguration 개선 업무에 기여할 기반이 됩니다.

**네트워크 접근제어 및 인증인가 체계 구축**

㈜가온누리정보시스템에서 대체거래소 **망분리 보안 체계**를 설계하고, **NAC**, **망연계**, **방화벽 이중화**를 구성했습니다. **RADIUS**와 **2FA**를 통합한 접근제어 체계를 구축하여 사용자 인증과 권한 부여를 중앙 집중화했으며, (주)아이티센 CTS에서는 **FortiGate**, **NAC**, **DLP**, **EDR**, **SIEM** 등을 통합 운영하며 다층 보안 아키텍처를 유지했습니다. ㈜메타넷엠플랫폼에서는 **OpenVPN** 기반 재택근무 인프라와 **VPN-NAC 연동** 원격 접근 체계를 구축하여, 원격 근무 환경에서도 낮은 보안 수준을 확보했습니다.

**금융권 컴플라이언스 및 감사 대응**

넷스트레이드 대체거래소 보안 인프라 구축과 운영 과정에서 **금융위원회 본인가 심사**를 대응하고 보안 아키텍처 기술 문서를 작성했습니다. (주)아이티센 CTS 재직 중 **금융감독원 정기 감사**를 대응했으며, **전자금융감독규정**, **ISMS**, **CCE** 점검 등 다양한 규제 요건에 대응했습니다. 이런 규제 대응 경험은 쿼팡의 정보통신망법, 전자금융거래법, 개인정보보호법 Compliance 관리에도 활용할 수 있습니다.

## 3. 부족한 부분과 보완 계획

**AWS Terraform Sentinel 및 CSPM 솔루션 직접 실무 경험**

Terraform 기반 인프라 보안 운영과 Ansible API 자동화 경험은 있으나, **AWS Terraform Sentinel Policy**나 전문 **CSPM(Cloud Security Posture Management)** 솔루션을 직접 도입하고 운영한 실무 경험은 제한적입니다. 이 부분은 쿠팡 입사 전까지 Terraform Sentinel 공식 문서와 HashiCorp 학습 리소스를 활용하여 정책 작성과 감시 모델을 학습하겠습니다. 또한 오픈소스 CSPM 도구를 개인 AWS 환경에 배포하여 Misconfiguration 탐지와 리스크 기반 우선순위 설정을 직접 실습할 계획입니다.

**CISSP / CISA 자격증 미보유**

현재 **CKS(CNCF)** 취득을 준비 중이며, CISSP과 CISA는 미보유 상태입니다. 보안 아키텍처와 리스크 관리 관련 지식 체계를 CISSP 공부를 통해 보완하고, 감사 및 컴플라이언스 관련 체계는 CISA 학습으로 정리할 계획입니다. 입사 후에도 업무를 수행하며 자격증 취득을 병행하여, 보안 전문성을 지속적으로 강화하겠습니다.

**e-Commerce 도메인 경험 부재**

이커머스 및 물류 산업의 보안 요구사항에 대한 직접적인 실무 경험은 없습니다. 다만 금융권에서 고객 자산과 거래 데이터를 보호한 경험, 그리고 대규모 인프라에서의 접근제어와 로그 감시 체계 구축 경험은 e-Commerce 환경의 보안 요구사항과 원리적으로 유사합니다. 입사 후 쿠팡의 물류 인프라와 결제 시스템 보안 아키텍처를 빠르게 파악하여, 도메인 지식을 적극적으로 쌓겠습니다.

## 4. 입사 후 포부

쿠팡에 입사하면 **AWS 퍼블릭 클라우드 인프라의 보안 요구사항 정의와 접근제어, 인증인가 체계**를 가장 먼저 깊이 이해하는 것을 목표로 삼겠습니다. 네트워크(Security Group, NACL, AWS Network Firewall)와 IAM 중심의 보안 설계 및 리뷰 업무에 기여하고, Terraform 기반 IaC 보안 정책 자동화와 CSPM Misconfiguration 개선을 통해 보안 상태를 지속적으로 향상시키겠습니다.

Kubernetes와 EKS 컨테이너 환경에서는 RBAC, Pod Security, Service Mesh 보안을 강화하여, 클라우드 네이티브 환경에서도 견고한 보안 경계를 유지하겠습니다. 또한 금융권에서 쌓은 컴플라이언스 대응 경험을 바탕으로, 정보통신망법, 전자금융거래법, 개인정보보호법 등 쿠팡이 준수해야 할 규제 요건에 능동적으로 대응하겠습니다.

단순히 사고를 막는 보안을 넘어, **개발과 운영팀이 신뢰할 수 있는 보안 파트너**가 되어 비즈니스 속도를 저해하지 않으면서도 안전한 인프라를 만드는 것. 그것이 쿠팡 Senior Security Engineer로서 제가 실현하고자 하는 목표입니다.
