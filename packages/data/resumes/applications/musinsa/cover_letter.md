# 무신사 Network Security Engineer 자기소개서

## 1. 지원 동기

무신사는 국내 대표적인 패션 플랫폼으로, 수많은 고객 데이터와 파트너사 연계를 기반으로 성장하고 있습니다. 이러한 환경에서 SaaS와 클라우드 기반 업무 환경의 보안은 핵심 경쟁력이라고 생각합니다.

저는 9년간 금융, 공공, 제조, 교육 분야에서 보안 인프라를 설계하고 운영했습니다. 특히 넥스트레이드 대체거래소 보안 인프라 구축 및 운영을 통해 금융권 수준의 보안 요구사항과 규제 대응 경험을 쌓았습니다. NAC, DLP, VPN 기반 접근통제와 데이터 보호 체계를 다수 구축했으며, API 연동과 스크립트를 활용한 보안 운영 자동화 경험도 보유하고 있습니다.

무신사의 SASE/CASB 기반 보안 환경 고도화와 SaaS 자산 보호에 기여하고자 지원하게 되었습니다.

## 2. 직무 관련 핵심 경험

**SASE 인접 접근통제 체계 구축**

메타넷엠플랫폼 재직 시 OpenVPN 기반 재택근무 VPN 인프라를 구축하고 VPN-NAC을 연동하여 원격 접근제어 체계를 설계했습니다. 천 명 이상 사용자 계정과 인증서를 Ansible로 자동화 관리했으며, VPN 세션 모니터링 및 비정상 접근 탐지 대시보드를 구축하여 사용자 행위 기반 이상탐지 체계를 마련했습니다.

가온누리정보시스템에서는 RADIUS와 2FA를 통합한 접근제어 체계를 구축했고, FortiGate HA 구성으로 고가용성 보안 인프라를 설계했습니다. 조인트리에서는 VMware NSX-T 분산 방화벽을 기반으로 서버 간 트래픽을 제어하고 가상 스위치 레벨 보안 정책을 중앙 집중화하여 마이크로세그멘테이션을 구현했습니다.

**CASB 인접 데이터 보호 및 DLP 운영**

아이티센 CTS에서 DLP 정책을 통합 운영하며 민감정보 접근 및 유출을 탐지하고 통제했습니다. 가온누리정보시스템에서는 DLP 솔루션을 신규 도입하고 정책을 설계했으며, 콴텍투자일임에서는 NAC와 DLP를 통합 관리하며 온프레미스와 AWS 하이브리드 환경의 데이터 흐름을 보호했습니다.

**보안 운영 자동화**

FortiManager API를 연동하여 방화벽 정책 배포를 자동화했고, 자동화 워크플로우와 Python 스크립트를 활용하여 보안 로그 분석 및 알림 체계를 자동화했습니다. 또한 Splunk 기반 상시 모니터링 체계를 운영하며 인시던트에 신속하게 대응했습니다.

## 3. 부족한 부분과 보완 계획

SASE, CASB, SWG, ZTNA 전용 솔루션을 직접 운영한 경험은 제한적입니다. 다만 NAC, DLP, VPN 기반 접근통제와 데이터 보호 경험을 통해 SASE/CASB 핵심 개념에 인접한 실무를 수행했습니다.

ZTNA 영역은 조인트리에서 VMware NSX-T 분산 방화벽으로 서버 간 트래픽을 제어하고 정책을 중앙 집중화한 경험, 그리고 메타넷에서 VPN-NAC 연동으로 원격 접근을 세분화 통제한 경험이 기반이 됩니다. 사용자 단말과 애플리케이션 수준의 세분화된 접근통제 정책 설계는 SASE 도입 시 빠르게 역량을 확장할 수 있는 출발점이라고 판단합니다.

정보보호 인증 정식 취득 경험을 보강하기 위해 현재 CKS(Certified Kubernetes Security Specialist) 자격증 취득을 준비하고 있습니다. 또한 SASE/CASB 관련 공식 교육 과정과 실습 환경을 활용하여 솔루션별 정책 운영 역량을 짧은 기간 내에 갖출 계획입니다.

## 4. 입사 후 포부

무신사 입사 후에는 SASE 보안정책의 안정적인 운영과 고도화에 집중하겠습니다. 사용자, 단말, 애플리케이션 수준의 접근제어 정책을 세분화하고, 원격 및 SaaS 접근에 대한 보안 기준을 명확히 하겠습니다.

CASB 영역에서는 사내 SaaS 이용현황을 가시화하고 Shadow IT를 식별하는 체계를 구축하겠습니다. 민감정보 접근, 공유, 다운로드, 외부반출에 대한 탐지와 통제 정책을 최적화하여 데이터 유출 위험을 줄이겠습니다.

또한 보안로그와 사용자행위 기반 이상탐지 분석 체계를 고도화하여 사전 예방적인 보안 대응 역량을 강화하겠습니다. 사용자 편의와 보안의 균형을 유지하며 유관부서와 협업하여 무신사의 안전한 업무 환경을 만들어가겠습니다.
