# Quantec AI Trading Platform - Technical Overview

## 프로젝트 개요

**기간**: 2022.08 ~ 2024.03 (1년 7개월)
**소속**: ㈜콴텍투자일임
**역할**: 인프라·정보보호팀 인프라 엔지니어
**규모**: 대규모 서버, 금융보안데이터센터(FSDC) 운영

---

## 시스템 아키텍처

### 인프라 구성

- **서버**: Linux/Windows 대규모 서버
- **스토리지**: 엔터프라이즈급 스토리지 시스템 형상관리
- **네트워크**: 망분리 환경 (외부망/내부망 물리적 분리)
- **클라우드**: AWS 하이브리드 인프라 (VPC, IAM, CloudTrail, GuardDuty)

### 보안 솔루션 스택

1. **데이터 보안**
   - DLP (Data Loss Prevention): 민감정보 유출 방지
   - DB 접근제어: 데이터베이스 쿼리 감사 및 접근 통제

2. **네트워크 보안**
   - VPN: 안전한 원격 접속 환경
   - 방화벽: 망분리 환경 정책 관리

3. **클라우드 보안**
   - AWS VPC: 가상 프라이빗 클라우드 격리
   - AWS IAM: 세분화된 권한 관리
   - AWS CloudTrail: API 호출 감사 로그
   - AWS GuardDuty: 지능형 위협 탐지

## 주요 성과

### 1. 운영 자동화 및 절차 표준화

**목표**: 반복 작업 자동화를 통한 운영 절차 표준화

**구현**:

- Python 스크립트 기반 인프라 자동화 시스템 개발
- 정기 점검 작업 자동화
- 로그 분석 및 리포팅 자동화

**성과**:

- 장애 대응 기준 정비
- 반복 작업 자동화
- 수작업 절차 표준화

### 2. 컴플라이언스 및 보안

**목표**: 금융규제 준수 및 데이터 보안 운영

**구현**:

- 금융감독원 정기 감사 대응 체계 구축
- 개인정보 보호 정책 수립 및 이행
- DLP 정책 강화 및 모니터링

**성과**:

- 금융감독원 정기 감사 통과 (중대 지적 없이 통과)
- 개인정보 유출사고 없이 운영 (근무 기간 연속)
- 금융감독원 감사 중대 지적 없이 통과 유지

### 3. 구성 최적화

**목표**: 시스템 구성 점검 및 리소스 최적화

**구현**:

- DB 접근제어 쿼리 튜닝
- 시스템 리소스 모니터링 및 최적화
- 병목 지점 분석 및 개선

**성과**:

- DB 접근제어 쿼리 튜닝 수행
- 쿼리 튜닝 수행
- 시스템 안정성 강화

### 4. PB 플랫폼 구축 검증

**목표**: 신규 PB(Private Banking) 플랫폼 성능 검증

**구현**:

- POC(Proof of Concept) 테스트 환경 구축
- 부하 테스트 및 성능 벤치마크
- 보안 취약점 사전 점검

**성과**:

- 목표를 상회하는 성능을 확인
- 프로덕션 배포 전 주요 이슈 사전 발견 및 해결
- 안정적인 시스템 런칭 지원

## 기술 스택

### Infrastructure

- **OS**: Linux (RHEL, Ubuntu), Windows Server
- **Virtualization**: VMware vSphere
- **Storage**: Enterprise SAN/NAS
- **Cloud**: AWS (EC2, VPC, S3, RDS)

### Security

- **DLP**: Data Loss Prevention
- **DB Access Control**: 데이터베이스 접근 제어
- **VPN**: Secure Remote Access
- **Cloud Security**: AWS IAM, GuardDuty, CloudTrail

### Automation & Monitoring

- **Scripting**: Python, Shell
- **Monitoring**: Zabbix, CloudWatch
- **Logging**: ELK Stack

## 교훈 및 인사이트

### 1. 금융권 보안의 중요성

금융권은 개인정보 및 금융 데이터를 다루기 때문에 보안이 최우선입니다. 근무 기간 동안 개인정보 보호 정책과 점검 절차를 운영한 것은 엄격한 보안 정책과
지속적인 모니터링의 결과입니다.

### 2. 자동화를 통한 운영 절차 표준화

반복적인 수작업을 Python 스크립트로 자동화하여 반복적인 수작업을 Python 스크립트로 자동화해 운영 절차를 표준화했습니다. 자동화는 단순히 시간 절약뿐만 아니라 인적 오류를 줄이고
일관성을 보장합니다.

### 3. 구성 최적화의 실질적 효과

DB 접근제어 쿼리 튜닝을 통해 DB 접근제어 쿼리 튜닝을 수행한 것은 DB 접근제어 쿼리 튜닝을 통해 시스템 구성과 응답 흐름을 점검했습니다. 구성 튜닝는 사용자 경험
개선과 직결됩니다.
