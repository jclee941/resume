엔지니어링 원칙

  • 관측 가능하지 않은 것은 운영할 수 없다 (You can't operate what you can't observe).
  • 수작업 → 자동화 파이프라인 → AI 에이전트 — 한 단계씩 점진적으로.
  • Defense in Depth: 네트워크 → ID → 워크로드 → 데이터.
  • 코드만 PR을 받는다 — 정책도, 인프라도, 운영 절차도.

현재 집중 영역

  • Splunk ES + n8n + FortiManager API 기반 SOC 운영
  • Cloudflare Workers Edge 기반 정책·관측·인증 통합 구조 학습
  • MCP/AI 에이전트로 보안 운영 수작업 아이템 정리 시도
  • GitOps(ArgoCD) + 정책 자동화(OPA) 학습
