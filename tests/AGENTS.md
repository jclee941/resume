## CONVENTIONS

- `npm run test:jest` discovers `unit/**/*.test.js` and `integration/**/*.test.js`.
- `npm test` chains Jest, dashboard, schemas/env, shared, tools, CLI, Python, and Go checks; E2E is separate.
- Package Node tests live beside source under `apps/`, `packages/`, and `tools/`; directory depth does not select the runner.
- `*.spec.js` belongs to Playwright; check existing imports before selecting a runner for a `*.test.js` file.
- Jest coverage thresholds are 90% globally over configured portfolio/shared sources, not every workspace.
- Read owner-dependent expected values through `helpers/owner-data.js`; run SSoT sync before those assertions.
- Fake fixtures mirror pack layout and are generated by `tools/scripts/content/make-fixtures.mjs`.
- Suites do not import `fixtures/content-pack/` directly; content tooling materializes it (`CONTENT_SOURCE=fixtures`).
- Register an event or state-change signal before triggering asynchronous work; keep its timeout bounded.

## ANTI-PATTERNS

- Do not replace deterministic waits with sleeps or retries that hide timing bugs.
- Do not weaken failure-path assertions or commit focused-only tests.
- Do not treat test-suite totals in historical reports as current verification evidence.
- Do not move package-colocated tests here merely to fit a single runner.
