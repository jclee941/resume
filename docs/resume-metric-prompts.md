# 이력서 정량 지표 작성 체크리스트 (Owner Only)

> 이 파일은 **비공개 작업용**입니다. 사이트에 렌더되지 않습니다.
> resume.jclee.me 콘텐츠 정량화 작업의 일부로 생성되었습니다.

## 배경

`packages/data/resumes/master/resume_data.json`의 `achievements` 항목을
**검증 가능한 사실**(아키텍처 규모, 카운트 가능한 산출물, 기술 구체성)로 정량화했습니다.

추측성 효과 수치(감소율, 시간 단축, 비용 절감)는 **본인만 아는 진실**이므로
임의로 넣지 않았습니다. 아래 질문에 실제 수치를 채우면 더 강한 정량 표현으로 업그레이드할 수 있습니다.

작성 후 적용 방법:

1. 아래 항목에 실제 수치 기입
2. `packages/data/resumes/master/resume_data.json`(+`_en`,`_ja`) achievements 수정
3. `npm run build` 실행 → 사이트 반영

## 적용된 안전 정량화 (현재 라이브)

거짓 없이 이미 반영된 사실 기반 수치:

- FortiGate **FGCP active-passive HA 2노드** + **5계층 망분리**

- Grafana Dashboard JSON **전량** 코드화 (Grafana-as-code)
- 컨택센터 **NAC 예외·단말 등록·현장 점검 3개 절차** Ansible 표준화
- 경력: **6개사 8년** (2017~2026), **자격증 7개**
