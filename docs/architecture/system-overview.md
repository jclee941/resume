# System Overview

## Purpose

This repository builds and operates the public portfolio and its in-process
job dashboard on Cloudflare Workers. Shared packages define contracts,
validation, environment parsing, and data boundaries; tools build and validate
the Worker and its content.

## Runtime composition

- The root [`wrangler.jsonc`](../../wrangler.jsonc) config selects
  `apps/portfolio/entry.js`, which serves the portfolio and forwards dashboard
  requests to the in-process dashboard runtime.
- The dashboard uses scheduled events, six Workflows, queues, a Durable Object,
  KV, D1, and Browser Rendering as declared in the root Worker configuration.
- Cloudflare Workers Builds is the production deployment authority. GitHub
  [`ci.yml`](../../.github/workflows/ci.yml) has one read-only validation job;
  it does not run E2E tests or deploy.

## Key Components

- `apps/portfolio/`: Public portfolio, Worker entry, and assets.
- `apps/job-dashboard/`: Dashboard HTTP, queue, scheduled-event, and Workflow
  runtime.
- `packages/`: Shared contracts, schemas, environment parsing, and data
  boundaries.
- `tools/`: Content transport, document generation, and repository operations.
- `tests/`: Unit, integration, and separately invoked E2E suites.

## Technology Stack

- **Languages**: JavaScript (ESM/CJS), Go, and Python.
- **Runtime**: Node.js and Cloudflare Workers.
- **Testing**: Jest and Playwright.
