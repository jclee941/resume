# Skipped E2E Tests Audit — Issue #24 / P1-6

**Status**: Active audit · **Owner**: Platform · **Last Updated**: 2026-05-05

This document inventories every skipped E2E test under `tests/e2e/`, classifies
each skip into one of four buckets (remove / fix now / keep with documented
guard / file follow-up), and prescribes the per-test action.

---

## Summary

| Bucket                                                                                                 |          Count | Action                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------ | -------------: | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A. Environment-conditional skips** (server unavailable, network unavailable, MCP server unavailable) | most of the 44 | Convert hard `test.skip(...)` to runtime guards via `test.fixme()` / `test.skip()` with `BASE_URL` / env-presence checks. CI sets the env vars when available. |
| **B. External-dependency skips** (Google OAuth, FortiManager, real Wanted)                             |        several | Keep skipped in default CI, gate behind a `RUN_EXTERNAL_E2E=1` env var, document required fixtures.                                                            |
| **C. Visual-regression baselines stale**                                                               | a small number | Regenerate baselines in a follow-up PR with `--update-snapshots`.                                                                                              |
| **D. Genuinely obsolete** (test target was removed)                                                    |          a few | Delete the test entirely.                                                                                                                                      |

## Required Environment Documentation

E2E spec files currently skip silently if any of these are absent. After
this audit, **each spec MUST log a clear "skipping because X is unset"
message** so CI logs explain the skip:

| Env var                       | Used by                        | If absent                           |
| ----------------------------- | ------------------------------ | ----------------------------------- |
| `BASE_URL`                    | most live-site specs           | skip with "BASE_URL not set" reason |
| `JOB_DASHBOARD_URL`           | dashboard, job-dashboard specs | skip                                |
| `MCP_SERVER_URL`              | mcp-server spec                | skip                                |
| `RUN_EXTERNAL_E2E`            | external-dep specs             | skip in default CI                  |
| `PLAYWRIGHT_UPDATE_SNAPSHOTS` | visual specs                   | only honored on opt-in PRs          |

The default CI run sets `BASE_URL=https://resume.jclee.me` (live site) and
leaves the others unset, so most specs run; the rest skip with explicit
reasons.

- [x] Classify each into bucket A/B/C/D.
- [x] Document required env vars and the explicit-skip-reason policy.


      the four-bucket policy.

      setup in `tests/e2e/AGENTS.md`.

      `npx playwright test --update-snapshots --project=chromium`. Verify
      diff is intentional.
- [ ] Bucket D: delete obsolete tests. Remove imports and fixture stubs
