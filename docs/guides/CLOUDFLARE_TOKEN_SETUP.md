# Cloudflare token setup (deprecated procedure)

> **Historical/deprecated guidance.** The former Global API Key setup,
> account-specific values, local plaintext-file steps, and manual deploy
> instructions are retired. Do not use this page to configure credentials.

Use the [1Password secret guide](ONEPASSWORD_RESUME_SECRETS.md) for current
credential handling and the
[deployment pipeline](../architecture/DEPLOYMENT_PIPELINE.md) for production
deployment. New deployment work should prefer a scoped API token. Some existing
integrations still support the legacy API-key/email pair; this page does not
claim that support is absent.
